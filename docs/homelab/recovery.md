# Homelab

The homelab documentation (node overview, network model, recovery order,
GitOps runbooks and recurring fixes) lives in the public import: see the
**homelab** section in the navigation. Literal identifiers (hostnames,
usernames, network details) have been replaced by generic placeholders — which
also makes the instructions reusable for anyone building something similar.

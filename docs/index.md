# Handbook

One hub that aggregates the documentation of every personal repo at build
time. The docs live in the project repos themselves (`/docs`, following the
[docs contract](conventions.md)); this handbook holds no project knowledge,
only the map. The navigation beside this page lists every imported project —
that list is generated from the inventory, so it is always current.

## Highlighted

- **Wanderer** — sovereignty checker for organisations
- **estafette** — proof-of-concept transferability assessment
- **wordsworth** — sovereign document pipeline

Also public: ash-nazg, Billbird (and its client), certswap, crible,
Gitsweeper, iso-audit, skill-forge and workstation-security.

There is a private build with additional sections as well; it is not
published.
